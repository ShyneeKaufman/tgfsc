# 🎣 TG-Fisch — Telegram Mini App Fishing Game

Полноценная игра-рыбалка прямо внутри Telegram, вдохновленная механиками хитовой игры **Fisch (Roblox)**.

---

## 🌟 Ключевые особенности

- **🎯 Аркадный кор-геймплей Fisch (HTML5 Canvas 60 FPS):**
  - Реалистичная анимация волн, покачивание поплавка и день/ночь освещение.
  - Динамический таймер поклёвки, зависящий от бланка удочки и наживки.
  - **Мини-игра вываживания:** физика инерции и гравитации бегунка (Sweetspot Bar), 4 типа поведения рыбы (`calm`, `darting`, `thrashing`, `erratic`), шкала прогресса и натяжения лески.
- **🧬 Глубокая система мутаций и редкостей:**
  - 6 тиров редкости: *Обычная, Необычная, Редкая, Эпическая, Легендарная, Мифическая, Абиссальная*.
  - 8 уникальных мутаций: *✨ Сияющая, ⚪ Альбинос, 🐋 Гигантская, 👑 Золотая, ☢️ Радиоактивная, 🌌 Порождение Бездны, 🌠 Космическая*.
  - Генерация точного веса рыбы и личные рекорды в FishDex.
- **🏝️ 4 биома и 35+ видов рыб:**
  - *Лазурная Бухта (Coast)*, *Затонувший Риф (Reef)*, *Марианская Бездна (Abyss)*, *Лавовая Кальдера (Caldera)*.
- **🏪 Прогрессия, Магазин и Садок:**
  - 7 разнообразных удочек со статами (Удача, Зона вываживания, Макс. вес).
  - Специальные наживки со стихийными баффами.
  - Вместительный садок с возможностью расширения и быстрой массовой продажи улова.
- **📱 Нативная интеграция с Telegram WebApp:**
  - Поддержка **Telegram Haptic Feedback** (вибрация при поклевке, вываживании и победе).
  - Автоопределение профиля (имя, аватар, ID).
  - Сохранение прогресса в `LocalStorage` и `Telegram CloudStorage`.
  - Синтезированный procedural Web Audio FX без тяжелых внешних аудио-файлов.

---

## 🛠️ Стек технологий

- **Фронтенд:** Vanilla JavaScript (ES Modules), HTML5 Canvas 2D, Vanilla CSS (Modern Dark Glassmorphism).
- **Сборщик:** Vite.
- **Платформа:** Telegram WebApp SDK.

---

## 🚀 Локальный запуск

```bash
# 1. Клонировать репозиторий
git clone git@github.com:ShyneeKaufman/tgfsc.git
cd tgfsc

# 2. Установить зависимости
npm install

# 3. Запустить локальный сервер разработки
npm run dev
```

После запуска открой в браузере: `http://localhost:5173/`

---

## 🌐 Сборка и Деплой

```bash
npm run build
```

- **Cloudflare Pages** (бесплатно, мгновенный HTTPS)
- **Vercel**
- **GitHub Pages**
